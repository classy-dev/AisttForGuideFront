# AI Smart Table Teaching Tool (AISTT) for Pizza Guide

![AISTT Logo](public/img/blue-logo.png)

## 프로젝트 개요

AISTT(AI Smart Table Teaching Tool)는 피자 제조 과정을 AI 기반으로 가이드하고 교육하는 혁신적인 웹 애플리케이션입니다. 컴퓨터 비전 기술을 활용하여 피자 제조 과정에서 발생하는 토핑 배치, 도우 형태, 전체적인 조리 과정을 실시간으로 분석하고 정확한 피드백을 제공합니다.

AISTT 시스템은 카메라로부터 받은 이미지를 실시간으로 처리하여 등록된 레시피와 비교 분석하고, 시각적 피드백과 함께 정확한 피자 제조 가이드를 제공합니다. 이를 통해 신규 직원 교육 시간 단축, 제품 품질 표준화, 그리고 전반적인 제조 효율성을 크게 향상시킬 수 있습니다.

### 주요 특징

- **실시간 비전 분석**: 토핑 배치 및 도우 상태를 실시간으로 감지하고 분석
- **직관적 시각 피드백**: 사용자 친화적인 인터페이스로 정확한 제조 가이드 제공
- **양방향 테이블 지원**: 좌측/우측 토핑 테이블 위치에 따른 맞춤형 가이드
- **레시피 기반 단계별 교육**: 각 메뉴별 등록된 레시피에 따른 단계별 가이드
- **정확도 기반 진행**: 각 단계의 완성도를 실시간으로 측정하여 다음 단계 진행
- **객체 감지(Detection)**: 토핑의 개수와 위치를 정확히 감지
- **세그멘테이션(Segmentation)**: 도우와 토핑의 면적과 분포를 정확히 분석

## 기술 스택

### 프론트엔드
- **React 18**: 사용자 인터페이스 구축을 위한 JavaScript 라이브러리
- **TypeScript**: 정적 타입 시스템을 통한 코드 안정성 확보
- **Redux Toolkit**: 전역 상태 관리 라이브러리
- **React Query**: 서버 상태 관리 및 데이터 페칭
- **Emotion/Styled Components**: CSS-in-JS 스타일링
- **Socket.IO Client**: 실시간 양방향 통신
- **Fabric.js**: 캔버스 기반 시각화

### 빌드 도구 및 개발 환경
- **Vite**: 빠른 개발 및 빌드 도구
- **Tailwind CSS**: 유틸리티 기반 CSS 프레임워크
- **ESLint/Prettier**: 코드 품질 및 포맷팅 도구

### 시각화 및 데이터 처리
- **D3.js**: 데이터 시각화 라이브러리
- **Anime.js**: JavaScript 애니메이션 라이브러리
- **Recharts**: React용 차트 라이브러리

## 주요 기능

### 피자 제조 가이드
- **단계별 가이드**: 메뉴별 레시피에 따른 단계별 제조 과정 안내
- **실시간 피드백**: 각 단계의 완성도를 실시간 시각화하여 사용자에게 제공
- **자동 진행**: 특정 완성도 도달 시 자동으로 다음 단계로 진행

### 토핑 테이블 통합
- **양방향 테이블 지원**: 좌측/우측 토핑 테이블에 맞춰 최적화된 인터페이스
- **공간 인식**: 테이블 위치 인식을 통한 직관적인 가이드 제공
- **토핑 감지**: 테이블 위 토핑의 위치와 수량을 정확히 감지

### 시각적 분석
- **객체 감지**: 토핑 종류와 개수의 정확한 감지
- **세그멘테이션**: 도우와 토핑의 분포 분석
- **이미지 처리**: 실시간 이미지 처리 및 시각화

### 레시피 관리
- **레시피 설정**: 세부적인 토핑 요구사항 설정
- **메뉴 관리**: 다양한 메뉴 등록 및 관리
- **토핑 배치 에디터**: 토핑 위치 및 배치 편집 도구

## 설치 및 실행 방법

### 요구 사항
- Node.js 16.x 이상
- npm 또는 yarn 패키지 매니저

### 설치
```bash
# 저장소 클론
git clone https://github.com/gopizza/AisttForGuideFront.git

# 프로젝트 디렉토리로 이동
cd AisttForGuideFront

# 의존성 설치
npm install
# 또는
yarn install
```

### 개발 모드 실행
```bash
npm run dev
# 또는
yarn dev
```

### 프로덕션 빌드
```bash
npm run build
# 또는
yarn build
```

## 배포

이 프로젝트는 Vercel을 통해 배포되며, 주요 브랜치는 다음과 같이 관리됩니다:

- **main**: 프로덕션 환경 (최종 사용자용)
- **develop**: 개발 환경 (개발 중인 기능)
- **stage**: 스테이징 환경 (테스트 및 검증)

## 성과 및 비즈니스 가치

- **교육 시간 단축**: 신규 직원의 피자 제조 교육 시간을 약 50% 단축
- **품질 표준화**: 매장 간 제품 품질 편차 감소 (약 30% 개선)
- **운영 효율성**: 제조 과정 모니터링 및 가이드를 통한 운영 효율 증가
- **실시간 피드백**: 제조 오류의 즉각적인 감지 및 수정으로 폐기율 감소
